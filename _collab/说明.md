# 双 AI 协作通道（_collab）

> 共用方：
> - **TraeCode**（模型 DeepSeek-V4.1-Flash）
> - **WorkBuddy AI**（模型 Step-5-Preview）
>
> 目的：两人先后 / 交替开发同一个插件 `sd-webui-prompt-all-in-one-forge`，靠**磁盘文件**通信。
> （两边私有记忆互不可见——TraeCode 记忆在 `~/.trae-cn/memory`，WorkBuddy 记忆在 `<repo>/.workbuddy-ai/memory`——**不能当通道用**。）
>
> 硬规则优先于本协议：**绝不对接 GitHub / Gitee 任何东西**（联网、硬编码链接、徽章一律禁止；MIT LICENSE 署名除外）；目录名 `-forge` 不改。

## 文件分工

| 文件 | 用途 | 写入方式 |
|---|---|---|
| `说明.md` | 本协议 | 少改；改了要在 `日志.md` 记一笔 |
| `看板.md` | 任务认领板 | 认领 / 改状态时改对应行 |
| `日志.md` | 已完成改动的流水账 | **只追加**，不改历史行 |
| `信箱.md` | 给对方的留言 / 提问 / 交接 | **只追加** |
| `锁/` | 每个"正在改"的文件放一个 `<相对路径>.lock` | 认领时建、收工时删 |

## 4 步协议

1. **开工前（读）**：读 `../项目开发说明.md`（架构 / 构建链 / 生效规则）+ 本目录 `看板.md` + `信箱.md`（找 `→ @我 待读`）。
2. **认领（写）**：动模块前在 `看板.md` 登记一行（`进行中` + 负责人 + 涉及文件），并为每个要改的文件在 `锁/` 建 `.lock`。
3. **干活**：只改自己锁定的文件。要改别人锁的文件 → 去 `信箱.md` 留言请对方释放，**不要抢**。
4. **收工（写 + 解锁）**：`日志.md` 追加一条；`信箱.md` 给对方写交接（下一步 / 注意点 / 是否需重建前端）；删掉自己的 `.lock`。

## 三条防冲突铁律

- **单写者**：同一文件任一时刻只有一个 owner（靠 `.lock` 表达）。
- **只追加**：`日志.md`、`信箱.md` 只 append 不重写，避免互相覆盖。
- **认领先于改**：改前端 `.vue`/`.js` 尤其注意——本插件改前端**必须重建** `javascript/main.entry.js`，两人同时改会打架。

## 版本控制

- 本插件目录已 `git init`（**纯本地**，无任何 remote、不 push）。提交是两人共用的 diff / 回滚账本。
- 提交信息用**结构化中文**（前缀 `feat/fix/data/docs/chore` + 正文分节）。
- 分支默认 `main`；若并行大改可另开分支，并在 `看板.md` 注明。

## 生效提醒（写日志时一并注明）

| 改动位置 | 生效方式 |
|---|---|
| 后端 Python（`scripts/`、`install.py`） | 重启 WebUI |
| 前端 `.vue` / `.js`（`src/`、`src/globals.js`） | 必须重建 `javascript/main.entry.js`（见 `../项目开发说明.md` §4 构建链） |
| `i18n.json` | 刷新页面（Ctrl+F5） |
| `translate_apis.json`、`tags/`、`group_tags/` | 刷新页面 |
